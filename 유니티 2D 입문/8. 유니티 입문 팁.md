# 팁
### C# 기본 문법과 다르게 유니티에선 main이 없다

<br>

> * **스크립트는 무조건 MonoBehaviour를 상속받아서 Component로 사용할 수 있음**  
> * **MonoBehaviour 클래스를 부모로 가지는 클래스는 전부 Start()를 가지고 있음**  
> * **Start()로 최초 한 번씩 실행을 하는 것을 main과 비슷하게 보면 됨**  

<br>

### 존재하는 스크립트는 전부 실행되지는 않고 오브젝트에 Component로 추가됐을 때만 실행됨

<br>

### Scene에 존재하는 모든 오브젝트가 화면에 보일 필요는 없다
* **소스코드 차원에서 존재하는 스크립트들을 보이지 않는 오브젝트에 넣어서 활용 가능**
