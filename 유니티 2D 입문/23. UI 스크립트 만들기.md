# UI 스크립트 만들기
**여러 UI에 전부 스크립트를 만들어 관리하면 복잡해짐**  
**따라서 제일 상위의 UI에 하나의 스크립트를 만들어 관리하는 것이 정석**

<br>

## UI_Test라는 Monobehavior Script 만들어서 UI_Test에 컴포넌트로 넣어주기
> **스크립트로 하위 UI들이랑 연결시켜줘야 함**  
>   
> ### UI 컴포넌트 연결시키기
> ```C#
> // UI_Test.cs
> using TMPro;
> using UnityEngine;
> 
> public class UI_Test : MonoBehaviour
> {
>     [SerializeField]
>     TextMeshProUGUI scoreText;
> 
>     void Start()
>     {
>         
>     }
> 
>     // Update is called once per frame
>     void Update()
>     {
>         
>     }
> }
> ```
> **`using TMPro;`: `TextMeshProUGUI` 쓰려면 넣어줘야 함**  
> **`Text`는 레거시 용이고 `TextMeshProUGUI` 써야함**  
> **이렇게 하면 유니티 툴에서 드래그 드롭으로 컴포넌트 연결 가능**
> 
> 
>   
> ```C#
> // UI_Test.cs
> void Start()
> {
>     scoreText.text = $"Score: {50}";
> }
> ```
> **`scoreText.text`로 텍스트 변경 가능**  

<br>

* **바뀔 예정이 없는 UI들은 굳이 연결시켜줄 필요 없음**

<br>

## 버튼 눌러서 작동시키기
> **버튼 UI 컴포넌트에 Button에서 설정 가능**  
> **On Click ()에 + 눌러서 행동 추가**  
> **오브젝트 하나 드래그해서 연결시켜주면 그 오브젝트에 붙어있는 모든 사항을 수정 가능**
>  
> ### 함수 호출
> ```C#
> //UI_Test.cs
> public void OnClickButton()
> {
>     Debug.Log("OnClickButton");
> }
> ```
> **1. 위의 함수를 UI_Test 스크립트에 추가해줌**  
> **2. 유니티로 돌아와서 버튼의 Button 컴포넌트에서 On Click () 수정**  
> **3. UI_test 오브젝트 연결 후 Function을 UI_test -> OnClickButton ()으로 설정**  
> **이제 누를때마다 `OnClickButton` 함수 호출** 
>
> ### 버튼 누를때마다 값 바꾸기
> ```C#
> //UI_Test.cs
> using TMPro;
> using UnityEngine;
> 
> public class UI_Test : MonoBehaviour
> {
>     [SerializeField]
>     TextMeshProUGUI scoreText;
> 
>     int score = 0;
> 
>     void Start()
>     {
>         scoreText.text = $"Score: {score}";
>     }
> 
>     // Update is called once per frame
>     void Update()
>     {
>         
>     }
> 
>     public void OnClickButton()
>     {
>         score += 10;
>         scoreText.text = $"Score: {score}";
>     }
> }
> ```
> **`int score = 0;`으로 변수 선언 후 초기화**  
> **`OnClickButton()`으로 버튼 한번 누를 때마다 10점 추가 후 `scoreText.text = $"Score: {score}";`로 UI 갱신**

<br>

## UI 갱신
> **UI를 갱신할 때 하드코딩으로 한줄 한줄 넣어주는 것 보다 하나의 함수로 관리하는 것이 좋음**  
> ```C#
> //UI_Test.cs
> using TMPro;
> using UnityEngine;
> 
> public class UI_Test : MonoBehaviour
> {
>     [SerializeField]
>     TextMeshProUGUI scoreText;
> 
>     int score = 0;
> 
>     void Start()
>     {
>         RefreshUI();
>     }
> 
>     // Update is called once per frame
>     void Update()
>     {
>         
>     }
> 
>     public void OnClickButton()
>     {
>         score += 10;
>         RefreshUI();
>     }
> 
>     void RefreshUI()
>     {
>         scoreText.text = $"Score: {score}";
>     }
> }
> ```
> **위와 같이 `RefreshUI()`같은 함수를 만들어 한번에 관리하면 체계적임**
