# 앵커
**폰 크기에 따라서 공백이 생길 수 있어서 UI가 불편하게 배치될 수 있으니 맞춰줘야 함**  

<br>

## UI엔 Transform이 아닌 Rect Transform이 있음
**UI 배치의 핵심적인 기능**  

<br>

### Width, Height는 크기
### Pos X, Y, Z는 UI 중앙의 좌표

<br>

### Pivot의 x y는 전체 비율을 기준으로 오브젝트의 중심을 정해줌(0.5, 0.5면 전체 비율의 50%, 50%만큼을 중심으로 정함)

### Pos 옆에 center middle은 앵커 프리셋
* **center를 기준으로 하는 좌표가 0,0**  

### Pivot은 자신을 기준으로 하고 앵커 프리셋은 부모를 기준으로 함

***

<br>

**포지션의 좌표는 앵커 프리셋에서 정한 기준부터의 거리를 나타냄**  
**앵커로 화면 위쪽을 기준으로 하여 UI를 설정해주면 다른 기종으로 바껴도 빈 공간 없이 위쪽에 잘 위치함**  

<br>

**앵커 프리셋을 stretch로 바꿔주면 화면에 맞춰서 UI 크기도 늘려줌**  
**프리셋 설정 시 shift 누르면 pivot도 같이 맞춰주고 alt 누르면 포지션도 같이 맞춰줌**
