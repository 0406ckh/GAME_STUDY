# 게임 오브젝트와 컴포넌트
**게임 오브젝트와 컴포넌트는 관리 측면에서 보면 한 몸이다** 

<br>

### Player 스크립트에서 색상 바꾸기
> **Player 클래스 안엔 level ,hp, damage는 있지만 sprite renderer은 없다**
> ```C#
> //Player.cs
> void Start()
> {
>     GameObject go = gameObject;
> }
> ```
> **이러면 연결 가능. gameObject는 현재 컴포넌트가 붙어있는 GameObject를 반환한다**  
>    <br>
>  
> ```C#  
> //Player.cs
> void Start()
> {
>     GameObject go = gameObject;
>     SpriteRenderer sr = go.GetComponent<SpriteRenderer>();
>     sr.color = Color.blue;
> }
> ```
> **이러면 색상이 바뀜**  
> **`SpriteRenderer sr = gameObject.GetComponent<SpriteRenderer>();`는 `SpriteRenderer sr = GetComponent<SpriteRenderer>();`로 해도 유니티에서 인식 함**  

### Player 움직이기
> ```C#
> //Player.cs
> void Start()
> {
>     SpriteRenderer sr = GetComponent<SpriteRenderer>();
>     sr.color = Color.blue;
> 
>     Transform t = gameObject.GetComponent<Transform>();  //Transform 컴포넌트 가져오기
>     t.position = new Vector3(5, 0, 0);
> }
> ```
> **`t.position.x = 5;`처럼 하나만 바꿀 수 없고 전체를 입력해줘야 한다**  
> **`gameObject.GetComponent<Transform>();`은 `GetComponent<Transform>();` 그리고 `transform;`으로 축약이 가능하다**  
> **따라서 위의 transform 2줄은 `transform.position = new Vector3(5, 0, 0);`으로 생략할 수 있다**
