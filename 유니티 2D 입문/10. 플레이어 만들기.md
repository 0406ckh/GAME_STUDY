# 플레이어 만들기

### 플레이어 만들기
> **1. 오브젝트 하나 만들어서 이름 Player 바꿔주기**  
> **2. Player 스크립트 하나 만들어서 Player 오브젝트 Component에 넣어주기**

<br>

### Player 스크립트에 변수를 넣어주면 유니티 Inspector에서 스크립트의 변수를 확인할 수 있음
```C#
using UnityEngine;
public class Player : MonoBehaviour
{
    public int level = 1;
    public int hp = 100;
    public int damage = 10;
    // Start is called once before the first execution of Update after the MonoBehaviour is created
    void Start()
    {
        
    }

    // Update is called once per frame
    void Update()
    {
        
    }
}
```
![Image](https://github.com/user-attachments/assets/253ec682-5ced-4003-ba6e-699349f98675)
### public이 아닌 private나 protected로 하면 유니티 툴에선 보이지 않음
```C#
[SerializeField]
int level = 1;
[SerializeField]
int hp = 100;
[SerializeField]
int damage = 10;
```
* **이렇게 해주면 public 아니라도 툴에서 보임**

<br>

### 툴에서 값 변경 가능
**값은 스크립트에서 입력한 값이 먼저 적용되고 유니티 툴로 덮어쓴 값이 적용 됨**
**따라서 툴에서 입력한 값이 최종적으로 입력이 됨**

<br>

***

**C# 클래스는 일종의 설계도**
**그 설계도로 만든 인스턴스가 설계대로 만들어진 객체**

### 유니티에서도 설계도와 인스턴스를 구분하는게 중요함
* **만들어져있는 스크립트는 설계도이고 그것을 오브젝트에 Component로 추가한 것이 인스턴스**
* **이렇게 추가가 되어야 메모리를 차지하게 됨**

<br>

**하나의 오브젝트를 복사해서 새 오브젝트를 만들었을 때 동일한 스크립트를 가지고 있지만 각각이 다른 인스턴스임**
