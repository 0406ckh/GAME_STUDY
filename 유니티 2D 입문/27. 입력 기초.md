# 입력 기초
**지금 하는 유니티 입력 처리 방식은 레거시라고 하는 옛날 방식**  
**하지만 가장 많이 사용되고 쉬움**  

<br>

### 키 로그 찍어보기
> ```C#
> // MainScript.cs
> void Update()
> {
>     // 눌렀을 때 한번만 true
>     if (Input.GetKeyDown(KeyCode.A))
>     {
>         Debug.Log("A Down");
>     }
> 
>     // 누르고 있는 동안 true
>     if (Input.GetKey(KeyCode.A))
>     {
>         Debug.Log("A Hold");
>     }
> 
>     // 키에서 손을 땔 때 한번만 true
>     if (Input.GetKeyUp(KeyCode.A))
>     {
>         Debug.Log("A Up");
>     }
> }
> ```
> **Input은 유니티에서 제공하는 클래스**  

<br>

### 마우스 로그 찍어보기
> ```C#
> // MainScript.cs
> void Update()
> {
>     // 마우스 눌렀을 때 한번만 true. 0은 좌클릭
>     if (Input.GetMouseButtonDown(0))
>     {
>         Debug.Log("Mouse Down");
>     }
> 
>     // 마우스 누르고 있는 동안 true.
>     if (Input.GetMouseButton(0))
>     {
>         Debug.Log("Mouse Hold");
>     }
> 
>     // 마우스 땠을 때 한번만 true
>     if (Input.GetMouseButtonUp(0))
>     {
>         Debug.Log("Mouse Up");
>     }
> }
> ```

<br>

### WASD  만들어보기
> **Horizontal, Vertical로 wasd 값 받아보기**
> ```C#
> // MainScript.cs
> void Update()
> {
>     // GetAxis는 축을 가져옴
>     // Horizontal은 수평(AD), Vertical은 수직(WS)
>     float value1 = Input.GetAxis("Horizontal");
>     float value2 = Input.GetAxis("Vertical");
>     Debug.Log($"{value1} {value2}");
> }
> **A와 W는 1, D와 S는 -1로 나오는 것을 확인 할 수 있음**  

<br>

### 모바일 입력
> **모바일 기기에는 키보드가 없기 때문에 Key A를 받으려고 할 때 만약 게임이 Simulater로 설정돼있으면 입력이 안됨**  
> **유니티 문서 확인해서 인풋에 관한 코드 보고 가져오기**
> ```C#
> // MainScript.cs
> void Update()
> {
>     if (Input.touchCount > 0)
>     {
>         // 터치 가져오기
>         Touch touch = Input.GetTouch(0);
> 
>         // 터치된 위치
>         Debug.Log(touch.position);
>     }
> }
> ```
> **이렇게 하면 모바일에선 인식 되고 컴퓨터 환경에선 인식 불가**  

<br>

### 맛보기 에셋 만들기
> **MainScript 오브젝트에 Player Input 컴포넌트 추가**  
> **Resource 폴더 밑에 우클릭 Create -> Input Actions 하면 직접 추가**  
> **Player Input 컴포넌트의 Actions 밑의 `Create Actions...`를 클릭하여 Assets의 Resources 폴더 밑에 넣어줘도 됨**  
> **`Create Actions...` 하면 조금 프리셋이 된 에셋 하나를 만들어줌** 
> **만들어진 파일을 클릭하면 창이 뜨는데 여기서 Control Schemes로 입력 장비들에 대한 각각의 설정 가능**
