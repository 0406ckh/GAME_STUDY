# 이벤트 함수
**게임은 유저가 종료를 할 때 까진 계속 실행이 돼야 하기 때문에 무한 루프를 돎**

<br>

### 무한 루프에서 하는 일
> **1. 입력 처리 `ex) 키보드, 마우스 등의 입력`**  
> **2. 게임 로직 실행 `ex) 플레이어의 이동, 몬스터가 공격하여 플레이어의 피가 줄어드는 상황 등 게임과 관련된 연산`**  
> **3. 렌더링: `화면에 현재 상태를 이미지나 모델로 보여주는 단계`** 

**위와 같은 루프가 얼마나 빨리 도는가에 따라서 게임의 연산 속도가 결정됨**  
60fps 같은 경우 1초에 60번 루프를 돎

<br>

***

## [유니티 이벤트 함수](https://docs.unity3d.com/kr/2021.3/Manual/ExecutionOrder.html) <- 유니티의 이벤트 함수를 볼 수 있음


### 사이트에 들어가서 스크립트 라이프사이클 플로우차트를 보면 루프를 도는 순서를 볼 수 있음
> 초기화 시 `Awake` -> `OnEnable` -> `Reset` 다음에 `Start`가 실행되는 것을 볼 수 있음  
> 따라서 `Awake` 함수에 코드를 넣어주면 `Start`보다 빠르게 실행을 할 수 있음
>   
> 나중이 되면 유니티에 스크립트가 많아져서 어떤 스크립트의 `Start`가 먼저 실행될지 알 수 없음  
> `Awake` 사용하면 따른 스크립트들의 `Start`보다 먼저 실행이 돼서 순서를 알기 편함  

<br>

### 초기화 다음 물리 연산과 관련된 함수들이 있음  
> 물리 연산과 관련된 부분들은 고정 프레임으로 실행해야 되는 경우가 많아 `FixedUpdate` 함수에 물리 관련 코드를 넣어줌

<br>

### 다음으로 Input 처리를 하고 Game Logic 함수들이 나옴  
> Game Logic에 `Update`와 `LateUpdate`를 자주 사용함  
> 모든 물체들의 업데이트가 종료된 후 실행이 되는 업데이트는 `LateUpdate`에 넣어주면 됨(카메라와 관련된 코드들이 여기에 많이 들어감)

<br>

**자주 사용하는 함수들: `Awake()`, `Start()`, `Update()`, `LateUpdate()`, `FixedUpdate()`**

<br>
