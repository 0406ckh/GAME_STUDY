# 인스턴스 관리#2

### 플레이어 여러명 만들기
> ```C#
> // MainScript.cs
> public class MainScript : MonoBehaviour
> {
>     public Sprite sprite;
>     public List<Player> players = new List<Player>();  	//플레이어 리스트
>     void Start()
>     {
>         for (int i = 0; i < 10; i++)					//플레이어 여러명 만들기
>             CreatePlayer();
>     }
> 
>     void CreatePlayer()
>     {
>         GameObject go = new GameObject();
>         go.name = "Player";
> 
>         SpriteRenderer sr = go.AddComponent<SpriteRenderer>();
>         Player player = go.AddComponent<Player>();
> 
>         players.Add(player);
>     }   
> }
> ```
> **이렇게 하면 10명의 플레이어가 생성되고 MainScript에서 아래와 같이 리스트로 관리할 수 있음**  
> ![Image](https://github.com/user-attachments/assets/168b734b-265a-4f25-9912-f6fd16eda0ab)  
> **특정 플레이어를 삭제하면 그 플레이어는 Missing(Player)로 바뀌며 삭제처리가 됨**  
> **그럼 Update에서 for문으로 리스트를 돌아가면서 연산을 할 때 if문으로 null 처리를 안해주면 `MissingReferenceException` 오류가 난다**  
> **아래와 같이 함수를 만들어 삭제 후 리스트에서 제거해주면 for문에서 문제가 일어나지 않는다**
> ```C#
> //MainScript.cs
> void RemovePlayer(Player player)
> {
>     GameObject.Destroy(player.gameObject);
> 
>     players.Remove(player);	// 리스트에서 제거
> }
> ```

<br>

* **앞으로는 플레이어나 몬스터 같은 인스턴스를 관리할 때 별도의 매니저 클래스를 파서 리스트로 관리함**
* **그때도 지금처럼 Create와 Remove를 대칭적으로 만들어서 관리하는 기법을 사용**
* **생명주기는 한쪽에서 몰아서 관리하는 것이 대부분의 경우에서 효율적이고 안정적이다**

```C#
// 랜덤으로 리스트에서 플레이어 하나를 제거하고 포문으로 돌리는 테스트 코드
// MainScript.cs
using NUnit.Framework;
using System.Collections.Generic;
using Unity.VisualScripting;
using UnityEngine;
 
public class MainScript : MonoBehaviour
{
    public Sprite sprite;
    public List<Player> players = new List<Player>();
    void Start()
    {
        for (int i = 0; i < 10; i++)
            CreatePlayer();

        int idx = Random.Range(0, 9);
        RemovePlayer(players[idx]);
    }
    void Update()
    {
        foreach(Player player in players)
        {
            GameObject go = player.gameObject;
        }
    }

    void CreatePlayer()
    {
        GameObject go = new GameObject();
        go.name = "Player";
        SpriteRenderer sr = go.AddComponent<SpriteRenderer>();
        Player player = go.AddComponent<Player>();

        players.Add(player);
    }

    void RemovePlayer(Player player)
    {
        GameObject.Destroy(player.gameObject);

        players.Remove(player);
    }
}
