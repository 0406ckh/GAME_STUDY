# 플레이어 vs 몬스터

**Time.deltaTime : 이전 프레임에서 현재 프레임까지 경과된 시간**

### 1초마다 연산하고 싶으면
```C#
float sumTime = 0;
void Update()
{
    sumTime += Time.deltaTime;  // sumTime에 이전 프레임부터 현재 프레임까지의 시간 추가
    if(sumTime >= 1)		      // sumTime이 1초를 넘으면 실행
    {
        Debug.Log("1초 경과!");
        sumTime = 0;
    }
}
```
<br>

### 플레이어가 몬스터를 1초마다 공격
```C#
float sumTime = 0;
void Update()
{
    sumTime += Time.deltaTime;
    if(sumTime >= 1)			// 1초마다 적 체력 감소
    {
        if (enemy.hp > 0)			// 적의 체력이 양수일때만 실행
        {
            enemy.hp -= damage;
            if (enemy.hp <= 0)		// 체력이 0 이하가 되면 죽었다고 출력
            {
                enemy.hp = 0;
                Debug.Log("몬스터 죽었음");
            }

            Debug.Log($"몬스터의 체력은 {enemy.hp}입니다");
        }
    sumTime = 0;
    }
}
```

<br>

**위에 방법은 한계가 명확함**
**게임이 출시되고 나면 유니티 툴에서 우리가 건드릴 수 없음**
**따라서 드래그해서 Player 오브젝트의 Enemy에 적을 직접 넣어주는 방법은 사용할 수 없음**
