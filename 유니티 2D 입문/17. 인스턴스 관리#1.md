# 인스턴스 관리#1
**여러 개의 플레이어를 만들 것이기 때문에 체계적인 관리가 필요함**

<br>

### 인스턴스 연결
> ```C#
> //MainScript.cs
> public class MainScript : MonoBehaviour
> {
>     public Sprite sprite;
>     public GameObject m_player; // 참조값을 들고있는 형태
>     void Start()
>     {
>         CreatePlayer();
>     }
> 
>     void CreatePlayer()
>     {
>         GameObject go = new GameObject();
>         go.name = "Player";
>         
>         SpriteRenderer sr = go.AddComponent<SpriteRenderer>();
>         Player player = go.AddComponent<Player>();
> 
>         m_player = go;		// 생성한 오브젝트를 플레이어에 할당
>     }
> }
> ```
> **툴에서 드래그로 인스턴스를 연결시켜주는 방식과 다르게 런타임에 생성된 인스터스도 연결할 수 있다**  

<br>

### 연결된 인스턴스 값 변경하기
> ```C#
> //MainScript.cs
> void Update()
> {
>     m_player.GetComponent<Player>().hp++;
> }
> ```

### `m_player`를 처음부터 Player 컴포넌트로 들고올 수 있다
> ```C#
> //MainScript.cs
> public Player m_player;
> void Update()
> {
>     m_player.hp++;
> }
> 
> void CreatePlayer()
> {
>     ...
>     m_player = player;
> }
> ```
> **위와 같이 짧게 줄일 수 있고 Update에선 GetComponenet가 아닌 바로 가져오기 때문에 부하가 조금이라도 줄어든다.**  

### 오브젝트/컴포넌트 삭제 시
> **`GameObject.Destroy(player);`로 컴포넌트를 삭제하였을 때 `m_player`는 Fake Null이 된다**  
> **유니티 툴에선 삭제된 것 처럼 보이지만 코드상 참조는 계속 남아있기 때문에 메모리엔 남아있다**  
> **하지만 원칙상 삭제한 오브젝트는 사용하면 안되기 때문에 Fake Null 처리를 하여 널 처럼 인식한다**  
> **여기서 `Update()`에 `GameObject go = player.gameObject;`를 넣어주게 되면 `MissingReferenceException` 에러가 뜬다**  
> **if문으로 null 비교를 해서 피해갈 수 있다(페이크 널이 연산 시 null로 처리됨)**
