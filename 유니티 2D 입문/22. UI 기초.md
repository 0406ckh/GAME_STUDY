# UI 기초
**이미지 파일을 가지고 화면에 올리는 방법은 크게 스프라이트랑 UI로 나눌 수 있다**

<br>

### Sprite와 UI 차이
> **게임 개발을 영화에 비유하면...**  
> **Sprite는 영화 배우: 카메라 위치가 움직이면 화면에서 Sprite의 위치도 바뀜**  
> **UI는 CG: 촬영을 끝내고 후 보정으로 넣는 느낌. 따라서 카메라와 무관히 별도로 존재**  
> **캐릭터가 이리저리 움직이는 게임은 Sprite, 비주얼 노벨같은 정적인 게임은 UI로 할 수 있음**  

<br>

### UI 생성하기
> **Hierarchy에서 우클릭 -> UI -> Image**  
> **Canvas라는 오브젝트가 생기고 그 밑에 Image가 생김**  
> **EventSystem도 따로 생김**

<br>

> * **UI는 카메라와 무관하게 최종적으로 화면에 들어감**  
> * **따라서 모든 UI 요소들은 캔버스라는 도화지 맡에서만 존재할 수 있음**  
> * **캔버스 밖으로 빼면 보이지 않는 오브젝트가 됨**
> <br>
>
> * **캔버스는 이름 변경 가능**  
> * **캔버스의 켄버스 컴포넌트에는 모든 UI들을 관리하는 역할**  
> * **캔버스 컴포넌트의 Sort Order는 무슨 UI를 먼저 보여줄지 정함**  

<br>

### UI 수정
> **이미지를 클릭하고 Scene에서 Rect tool**  
> **움직이거나 크기 변경 가능**  
> **이후 소스 이미지를 넣어주면 배경처럼 사용 가능**

<br>

### TextMeshPro 생성
> **1. UI -> Text - TextMeshPro 선택 (UI -> Legacy -> Text도 있지만 구식이라 안씀)**  
> **2. TMP Importer라는 텍스트 메쉬 프로를 사용하기 위한 라이브러리를 불러오는 옵션이 뜸**  
> **3. Import TMP Essentials 눌러서 Import**  
> **4. Assets 하위에 TextMesh Pro 파일이 생김**  
> **5. Text Input의 사각형에 입력하면 화면에 보임**

**한국어 입력하면 깨짐. 추후 한국어 지원하는 버전으로 수정**  
**TMP가 Legacy보다 훨씬 기능이 많고 효율적임. TMP는 에셋 형식으로 관리 가능**

<br>

### 버튼 생성
> **1. UI -> Button - TextMeshPro**  
> **2. 캔버스 아래 Button이 만들어지고 그 하위에 Text(TMP)가 만들어짐**  
> **버튼은 클릭을 인식해 동작**
