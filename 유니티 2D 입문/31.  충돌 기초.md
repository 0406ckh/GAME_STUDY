# 충돌 기초
플레이어가 바닥에 서 있는 상태로 유지, 물체끼리 부딪혀 튕겨나감, 영역에 들어가서 상호작용 하는 것들을 구현하기 위한 기술  
게임 엔진에선 기본적으로 물리 엔진과 동시에 충돌 판정 기능을 제공함  

<br>

### 충돌 실습
이동, 추적 때 사용한 몬스터, 플레이어 오브젝트를 사용
몬스터 스크립트는 기본으로 초기화
오브젝트에 2개의 컴포넌트를 추가해야 함

### Rigidbody 2D
> **물리 기반의 물리 연산을 하는 컴포넌트**  
> Rigidbody에서 중력을 적용시켰기 때문에 이대로 실행시키면 물체들이 아래로 떨어짐  
> ㄴ Rigidbody에 `Body Type`을 `Dynamic`에서 `Static`으로 바꾸면 떨어지지 않음
>     
> 움직이지 않을 때는 `Static`, 움직일 때는 `Dynamic`이나 `Kinematic`  
> `Dynamic`은 유니티 물리 엔진의 영향을 받는다는 의미
> `Dynamic`으로 설정 하고 `Gravity Scale`을 0으로 하면 중력을 받지 않음
> `Kinematic` 유니티 물리 엔진의 영향을 받지 않고 코드 상에서 적용하겠다는 의미
>   
> Rigidbody의 `Simulated`를 끄면 물리엔진 적용되지 않음
>   
> `Constraints`로 물제의 x y z 포지션을 고정할 수 있음  

### Circle Collider 2D
> **충돌 영역(오브젝트 형태에 맞춰서 정해주면 됨)을 설정하는 컴포넌트**  
> Collider 안에 `Edit Collider`로 크기 조정 가능  

<br>

### 충돌, 트리거 로그 코드
```C#
// Player.cs
public class Player : MonoBehaviour
{
    public float speed = 5.0f;

    // Update is called once per frame
    void Update()
    {
        float moveDistance = speed * Time.deltaTime;
        Vector3 moveDirection = Vector3.zero;

        if (Input.GetKey(KeyCode.W))
        {
            moveDirection += Vector3.up;
        }
        if (Input.GetKey(KeyCode.A))
        {
            moveDirection += Vector3.left;
        }
        if (Input.GetKey(KeyCode.S))
        {
            moveDirection += Vector3.down;
        }
        if (Input.GetKey(KeyCode.D))
        {
            moveDirection += Vector3.right;
        }

        transform.position += moveDirection.normalized * moveDistance;
    }

    // 충돌 시작
    private void OnCollisionEnter2D(Collision2D collision)
    {
        Debug.Log("Player - OnCollisionEnter2D");
    }

    // 충돌 중
    private void OnCollisionStay2D(Collision2D collision)
    {
        Debug.Log("Player - OnCollisionStay2D");
    }

    // 충돌 끝
    private void OnCollisionExit2D(Collision2D collision)
    {
        Debug.Log("Player - OnCollisionExit2d");
    }

    // 물체가 포개졌을 때
    private void OnTriggerEnter2D(Collider2D collision)
    {
        Debug.Log("Player - OnTriggerEnter2D");
    }

    // 물체가 포개지는 중
    private void OnTriggerStay2D(Collider2D collision)
    {
        Debug.Log("Player - OnTriggerStay2D");
    }

    // 물체가 빠져나갈 때
    private void OnTriggerExit2D(Collider2D collision)
    {
        Debug.Log("Player - OnTriggerExit2D");
    }
}
```
`Monster.cs`에도 위와 같은 함수 추가  
현재까진 아무 로그도 뜨지 않음  
물체가 둘 다 Kinematic일 때 둘 중 하나라도 `Use Full Kinematic Contacts`를 켜야 충돌이 일어남  
대신 코드에 뭐가 없기 때문에 그냥 통과되고 로그만 뜸  

<br>

충돌이 아닌 영역 안에 들어왔는지 판별하고 싶으면 `Is Trigger`를 켜야함
Collider 컴포넌트 안의 `Is Trigger`를 켜면 Trigger 디버그 로그가 뜸
한쪽만 켜놔도 Trigger로 취급
Collision과 Trigger가 동시에 뜨는 일은 없음

### 포탈 만들어보기
> 1. 오브젝트 생성 후 이름 Portal로 변경  
> 2. `Monobehaviour Script`를 Portal로 생성  
> 3. 게임 오브젝트에 스크립트 추가 후 `RigidBody 2D`와 모양에 맞는 `Collider 2D`추가  
> 4. `Kinematic`으로 설정 후 트리거 모드 키기  
> 5. `Portal.cs`에 아래 함수 추가
> ```C#
> // Portal.cs
> private void OnTriggerEnter2D(Collider2D collision)
> {
>     // 플레이어만 포탈에 상호작용 하게 만들기
>     Player player = collision.gameObject.GetComponent<Player>();
>     if (player == null)
>         return;
> 
>     Debug.Log("Portal Trigger");
> }
> ```

### 레이어로 포탈 상호작용 오브젝트 설정하기
> 1. 오브젝트에 Layer에서 Add layer로 Monster와 Player 레이어 만들기  
> 2. 플레이어는 Player 레이어로 몬스터는 Monster 레이어로 설정  
> 3. Portal 오브젝트의 Collider 컴포넌트에서 `Layer Overrides`의 `Exclude Layers`를 Monster로 설정  

레이어로 구별하는게 체계적이고 효율적임
