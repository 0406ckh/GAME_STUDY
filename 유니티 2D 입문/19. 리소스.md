# 리소스

### 스프라이트 코드로 설정
> **Packages -> 2D Sprite -> Editor -> ObjecMenuCreation -> DefaultAssets -> Textures -> v2에 Circle이 있음**  
> **복사해서 Assets 밑에 Resources(철차 중요. 반드시 복수형) 폴더 만들어서 안에 붙여넣기**  
> **이제 `public Sprite sprite;`는 지우고 `sr.sprite`를 아래처럼 바꿔주면 됨**
> ```C#
> // MainScript.cs
> void CreatePlayer()
> {
>     GameObject go = new GameObject();
>     go.name = "Player";
>     go.tag = "Player";
> 
>     SpriteRenderer sr = go.AddComponent<SpriteRenderer>();
>     sr.sprite = Resources.Load<Sprite>("Circle");
>     sr.color = Color.green;
> 
>     Player player = go.AddComponent<Player>();
> }
> ```
> **`Resources.Load<Sprite>("Circle");` 에서 " "안에 Resources 파일 산하에서 어떤 경로인지 상대 경로를 입력해줘야 함**    
> **Resources 폴더 안에 있는 리소스만 사용 가능**  
> **Resources 폴더에 Circle 바로 넣어줬기 때문에 그냥 Circle만 입력하면 됨**  

<br>

***

**File -> Build Profiles에서 원하는 플랫폼 선택 후 Build And Run 하면 폴더가 만들어짐**  
**폴더에서 `프로젝트명.exe`를 실행하면 게임이 실행됨**  
**폴더를 보면 `프로젝트명_Data` 폴더가 있는데 여기에 게임을 실행할 떄 필요한 모든 리소스들이 압축되어 들어가있음**  

<br>

### Build Profiles 할 때 Scene을 골라줄 수 있음
> **선택한 Scene에 올라가있는 모든 오브젝트와 리소스는 필요하다고 유니티에서 인지함**  
> **따라서 다른 경로에 있는 에셋들도 포함돼있으면 빌드에 포함시킴**  
> **그리고 우리가 만든 Resources 폴더에 있는 모든 에셋들은 빌드에 포함 돼서 들어감**  
> **따라서 resources 폴더는 굉장히 편리하지만 불필요한 에셋들도 추가될 수 있음**  

<br>

**게임 용량은 큰데 실행시켜보면 메모리를 전부 차지하진 않음**  
  * **실행 시 리소스를 전부 사용하는 것이 아닌 필요한 리소스만 적절하게 사용하기 때문**  

<br>

**리소스는 로딩해서 메모리에 가지고 왔을 때만 사용할 수 있음**  
**`Resources.Load<>();`가 그 역할을 해줌**  
**SSD에 있던 데이터 파일들을 로딩해서 메모리에 가져와 사용하는 작업**
