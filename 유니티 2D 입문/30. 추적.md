# 추적
**몬스터가 플레이어를 따라가거나 유도탄이 적을 찾아갈 때 필요함** 

<br>

### 플레이어 위치 파악하는 몬스터
```C#
// Monster.cs
public class Monster : MonoBehaviour
{
    Player player;
    void Start()
    {
        // 플레이어 찾아서 연결
        player = GameObject.FindAnyObjectByType<Player>();
    }

    void Update()
    {
        // 플레이어의 위치에서 자신의 위치를 빼면 플레이어로 가는 방향이 구해짐
        // 현재는 방향과 거리까지 전부 가지고 있음
        Vector3 direction = player.transform.position - transform.position;

        // direction.magnitude는 벡터의 거리를 확인할 수 있고
        // direction.normalized는 정규화하여 방향을 확인할 수 있음
        Debug.Log(direction.magnitude);
        Debug.Log(direction.normalized);
    }
}
```

### 플레이어 따라가는 몬스터
```C#
// Monster.cs
public class Monster : MonoBehaviour
{
    Player player;

    public float speed = 3f;
    void Start()
    {
        // 플레이어 찾아서 연결
        player = GameObject.FindAnyObjectByType<Player>();
    }

    void Update()
    {
        float moveDistance = speed * Time.deltaTime;

        Vector3 direction = player.transform.position - transform.position;

        transform.position += direction.normalized * moveDistance;
    }
}
```

<br>

### 플레이어가 일정 거리 이하일 때만 따라가는 몬스터
```C#
// Monster.cs
public class Monster : MonoBehaviour
{
    Player player;

    public float speed = 3f;
    void Start()
    {
        // 플레이어 찾아서 연결
        player = GameObject.FindAnyObjectByType<Player>();
    }

    void Update()
    {
        float moveDistance = speed * Time.deltaTime;

        Vector3 direction = player.transform.position - transform.position;

        // 거리가 5 이하일 때만 따라가게 설정
        if (direction.magnitude < 5)
        {
            transform.position += direction.normalized * moveDistance;
        }
    }
}
```
