# 인스턴스 삭제 및 비활성화

### 인스턴스 삭제하기
> ```C#
> //MainScript.cs
> void CreatePlayer()
> {
>     GameObject go = new GameObject();
>     go.name = "Player";
> 
>     Player player = go.AddComponent<Player>();
> 
>     GameObject.Destroy(go, 3);
> }
> ```
> **`GameObject.Destroy(go, 3);` : 3초뒤에 go를 삭제함**  
> **첫번쨰 인자는 오브젝트, 두번째 인자는 시간. 두번째 인자 입력 안하면 바로 삭제 됨**  

* **`GameObject.Destroy();`는 Object를 인자로 받음** 
* **Object는 base class이기 때문에 게임 오브젝트 뿐만 컴포넌트 같은 모든 클래스 지정해서 삭제할 수 있음**
* **따라서 `GameObject.Destroy(player);` 하면 player 컴포넌트만 사라진 것을 볼 수 있음**

<br>

### 인스턴스 비활성화/활성화 하기
> ```C#
> //MainScript.cs
> void CreatePlayer()
> {
>     GameObject go = new GameObject();
>     go.name = "Player";
>  
>     Player player = go.AddComponent<Player>();
> 
>     go.SetActive(false);		 // 게임 오브젝트 단위
>     player.enabled = false;	     // 컴포넌트 단위
> }
> ```
> **`go.SetActive();`에 false를 넣어주면 비활성화, true를 넣어주면 활성화가 됨**  
> **컴포넌트 단위로 비활성화 하고 싶으면 `player.enabled = false;`처럼 할 수 있음**
