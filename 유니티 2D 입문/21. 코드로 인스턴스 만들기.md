# 코드로 인스턴스 만들기

### 프리팹으로 인스턴스 만들기
> ```C#
> // MainScript.cs
> public class MainScript : MonoBehaviour
> {
>     public GameObject prefab;   // 프리팹 로딩
> 
>     void Start()
>     {
>         CreatePlayer();
>     }
>     void CreatePlayer()
>     {
> 
>     }
> }
> ```
> **프리팹은 예외적으로 Scene에 존재하지 않아도 GameObject 타입으로 선언 가능**  
> **이럼 MainScript에 다음과 같이 Prefab이 있는것을 확인할 수 있음**  
> ![Image](https://github.com/user-attachments/assets/cdb2cddf-7feb-4525-9cc2-a9080ebf66fe)  
> **이 프리팹은 리소스의 개념**  
> **여기에 플레이어 프리팹 드래그해서 넣어줌**  

<br>

> ```C#
> // MainScript.cs
> void CreatePlayer()
> {
>     GameObject go = Object.Instantiate(prefab);
> }
> ```
> **Object.Instantiate(prefab); : prefab을 복제해서 인스턴스를 만듦(GameObject를 리턴)**   
> **실행하면 Player(Clone)이라는 이름의 오브젝트 만들어짐**  
> **아래와 같이 하면 (Clone) 없이 그냥 Player로 만들 수 있음**  
> ```C#
> // MainScript.cs
> void CreatePlayer()
> {
>     GameObject go = Object.Instantiate(prefab);
>     go.name = prefab.name;
> }
> ```

<br>

### 드래그 없이 바로 프리팹 설정해주기
```C#
// MainScript.cs
public class MainScript : MonoBehaviour
{
    GameObject prefab;
    void Start()
    {
        prefab = Resources.Load<GameObject>("Player");     // 플레이어 만들 때마다 리소스 로딩할 필요 없으니 처음 한번만

        CreatePlayer();
    }
    void CreatePlayer()
    {
        GameObject go = Object.Instantiate(prefab);
        go.name = prefab.name;
    }
}
```

### 프리팹으로 인스턴스 생성 후 리스트에 넣어서 관리하기
```C#
// MainScript.cs
using NUnit.Framework;
using System.Collections.Generic;
using Unity.VisualScripting;
using UnityEngine;

public class MainScript : MonoBehaviour
{
    GameObject prefab;

    List<Player> players = new List<Player>();

    void Start()
    {
        prefab = Resources.Load<GameObject>("Player");

        for(int i = 0; i < 5; i++)
            CreatePlayer();
    }

    void CreatePlayer()
    {
        
        GameObject go = Object.Instantiate(prefab);
        go.name = prefab.name;
        Player player = go.GetComponent<Player>();

        players.Add(player);
    }
}
```
