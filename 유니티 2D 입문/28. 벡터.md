# Vector
벡터를 숙지해야 유티니 상에서의 이동을 구현할 수 있다

### 좌표
좌표가 존재하려면 좌표계라는 개념이 존재해야함  
기준이 있어야 좌표가 의미가 있어짐  
기준에서 좌우(x), 상하(y) 같은 축이 마련이 되고 거기서 (3, 4)같은 좌표가 생김

<br>

### 벡터 <sub>크기 + 방향</sub>
#### 벡터는 크기와 방향만 가지고 있고 어디서 시작하는지는 포함하지 않는다  
```math
\overrightarrow{v_{AB}} = (B_x - A_x, B_y - A_y, B_z - A_z)
```
B가 (4, 5, 0) A가 (1, 1, 0)이면 벡터($$\overrightarrow{v_{AB}}$$)는 (3, 4, 0)  
<br>
#### 벡터 스칼라 곱은 앞의 스칼라를 그대로 좌표에 각각 곱해주면 된다  
$$\overrightarrow{v_1} = (x_1, y_1, z_1)$$  
$$k\overrightarrow{v_1} = (kx_1, ky_1, kz_1)$$  
<br>
#### 벡터끼리 덧셈은 각 좌표를 더해주면 된다(뺄셈도 동일)  
$$\overrightarrow{v_1} = (x_1, y_1, z_1)$$  
$$\overrightarrow{v_2} = (x_2, y_2, z_2)$$  
$$\overrightarrow{v_1} + \overrightarrow{v_2} = (x_1 + x_2, y_1 + y_2, z_1 + z_2)$$  
$$\overrightarrow{v_1} - \overrightarrow{v_2} = (x_1 - x_2, y_1 - y_2, z_1 - z_2)$$  
<br>
#### 교환 법칙(벡터를 더하는 순서는 중요하지 않다)  
$$\overrightarrow{v_1} = (x_1, y_1, z_1)$$  
$$\overrightarrow{v_2} = (x_2, y_2, z_2)$$  
$$\overrightarrow{v_1} + \overrightarrow{v_2} = \overrightarrow{v_2} + \overrightarrow{v_1}$$  
<br>
#### 결합 법칙(벡터를 여러개 더할 때 순서는 중요하지 않다)  
$$(\overrightarrow{v_1} + \overrightarrow{v_2}) + \overrightarrow{v_3} = \overrightarrow{v_1} + (\overrightarrow{v_2} + \overrightarrow{v_3})$$  

<br>

### 벡터의 크기 구하기(Magnitude)  
$$\overrightarrow{v_{AB}} = (v_x, v_y, v_z) = (3, 4, 0)$$  
$$\left\vert\overrightarrow{v_{AB}}\right\vert = \sqrt{v^2_x + v^2_y + v^2_z} = 5$$

<br>

### 정규화(Normalize)
방향만 보기 위해서 크기가 1인 벡터(단위벡터)로 만듬
```math
\begin{align}
\overrightarrow{v_{AB}} = (v_x, v_y, v_z) = (3, 4, 0)\\
\left\vert\overrightarrow{v_{AB}}\right\vert = \sqrt{v^2_x + v^2_y + v^2_z}\\
\overrightarrow{n} = (\frac{v_x}{\sqrt{v^2_x + v^2_y + v^2_z}  }, \frac{v_y}{\sqrt{v^2_x + v^2_y + v^2_z}}, \frac{v_z}{\sqrt{v^2_x + v^2_y + v^2_z}})
\end{align}
```
플레이어의 속도에 따라서 이동을 할 때 정규화된 벡터에 이동하고 싶은 크기를 곱해서 이동을 처리하면 된다

<br>

### 위치 벡터
벡터를 위치 표현 용도로 사용하는 것이다  
좌표는 원점을 기준으로 한 방향 벡터로 간주해도 된다  
(1, 1) 같은 좌표가 아닌 $$v_A(1, 1)$$같은 위치 벡터로 사용하게 되면 벡터 클래스로 활용 가능하다  
벡터끼리 덧셈이 가능하니 이동 시 벡터 덧셈을 할 수 있어서 편하다
