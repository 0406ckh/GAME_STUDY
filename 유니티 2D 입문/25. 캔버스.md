# 캔버스

## 해상도 대응
**여러 기기에 대응하려면 해상도 관리가 필요함**

<br>

***

**유니티에서 왼쪽 아래의 Game 탭에서 Game을 Simulator로 바꿔주면 모바일 기기들에 뜨는 화면을 미리 볼 수 있음**  
**Display1 옆에 해상도 추가 가능**  

<br>

> **Canvas 생성**  
> **Simulator에서 갤럭시 S7 선택(1440x2560)**  
> **Canvas아래 Image의 Rect Transform에서 Width, Height를 절반으로 맞춰주기(720,1280)**  

<br>

## Canvas 오브젝트를 보면 Rect Transform, Canvas, Canvas Scaler라는 컴포넌트가 있음

<br>

### Rect Transform의 Width와 Height은 현재 시뮬레이터에 있는 기종의 해상도 보여줌

<br>

### Canvas의 Render Mode에 Overlay, Camera, World space가 있음  
* **Overlay는 카메라에 영향을 받지 않는 UI**  
* **Camera는 카메라에 영향을 받는 UI**  

<br>

### Canvas Scaler에 UI Scale Mode는 캔버스 내에 있는 UI 요소들이 어떻게 스케일링 될지 결정함

**Constant Pixel Size를 고르면 지금 Canvas에 있는 UI 사이즈가 고정돼서 다른 기종으로 바꿔도 똑같은 크기로 유지됨**  

<Br>

**Scale With Screen Size는 화면에 맞게 해상도를 스케일링 함**  
**밑의 Reference Resolution에 기준 크기를 넣어주면 됨(S7에서 작업할거면 1440, 2560)**   

<br>

**Game에서 해상도 1440x2560과 2880x5120을 추가하고 화면을 확인해보면 똑같이 보임**  
**하지만 Canvas에 Rect Transform을 보면 Scale이 2로 바뀌어 있는 것을 볼 수 있음**  

<br>

**1440x5210을 추가해주면 Scale이 안바뀌고 그대로인 것을 확인할 수 있음**  
**정배로 늘어나는게 아니면 세로로 길어지거나 가로로 길어서 UI가 이상해보일 수 있기 때문**  

<br>

**Reference Resoulution 밑의 Screen Match Mode로 이에 대한 규칙을 정해줄 수 있음**  
> * Match Width Or Height는 세로를 먼저 맞출지 가로를 먼저 맞출지 정할 수 있음
>   * Match에서 세로와 가로 어디로 맞출지 비율 정해줄 수 있음
> * Expand는 게임 화면은 그대로 두고 화면을 늘림. 게임화면이 무조건 카메라 안에 들어오게 해줌
> * Shrink는 게임 화면에 맞게 화면을 줄임. 게임화면이 카메라 밖으로 튀어나갈 수 있음
