# 인스턴스 찾기

### 이름으로 인스턴스 찾기
> ```C#
> //MainScript.cs
> void Update()
> {
>     GameObject go = GameObject.Find("Player");
>     if(go != null)
>     {
>         Debug.Log("Found Player");
>     }
> }
> ```
> **`GameObject.Find("Player");`에서 오브젝트 이름으로 가져올 수 있음**  
> **만약 없다면 null을 반환하기 때문에 꼭 if문으로 null 확인 해줘야 함**

<br>

### 태그로 인스턴스 찾기
> ```C#
> //MainScript.cs
> void Update()
> {
>     GameObject go = GameObject.FindGameObjectWithTag("Player");
>     if(go != null)
>     {
>         Debug.Log("Found Player");
>     }
> }
> ```
> **Tag는 툴에서 Inspector의 이름 밑에 Tag 탭에서 바꿀 수 있음**  
> **Tag 추가는 Tag 탭 밑의 Add Tag에서 추가 가능**  
> **아래와 같이 생성 시 태그도 달아줄 수 있음**  
> ```C#
> //MainScript.cs
> void CreatePlayer()
> {
>     GameObject go = new GameObject();
>     go.name = "Player";
>     go.tag = "Player";
> }
> ```

<br>

### 컴포넌트로 인스턴스 찾기
> ```C#
> //MainScript.cs
> void Update()
> {
>     Player player = GameObject.FindAnyObjectByType<Player>();
>     if(player != null)
>     {
>         Debug.Log("Found Player");
>     }
> }
> ```
> **게임 오브젝트가 아닌 게임 오브젝트가 들고 있는 Player를 한번에 찾아줌**
