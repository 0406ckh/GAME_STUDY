# 인스턴스 상호작용

### Monster 만들기
> **1. Monster 오브젝트랑 스크립트 하나 만들어주기**  
> **2. 스크립트에 level, hp, damage도 플레이어랑 똑같이 추가**  
> **3. Monster 오브젝트에 컴포넌트로 Monster 스크립트 추가**  

<br>

### 오브젝트 자신의 값을 바꾸는건 쉬움
> ```C#
> void start()
> {
>      hp = 50;
> }
> ```  
> **위에서 hp는 this.hp와 똑같음**  
> **게임 실행 시 hp가 50으로 바뀜**  

<br>

### 객체 연결시켜주기
**객체들끼리는 연결되어있지 않기 때문에 연결시켜주어야 함**
> ```C#
> [SerializeField]
> GameObject enemy;
> ```
> **위를 추가하면 유니티 툴의 player 스크립트에 Enemy가 추가됨**  
> **몬스터 오브젝트를 드래그 해서 Enemy에 넣어주면 값에 몬스터 오브젝트가 들어감**

<br>


### 이렇게 바꿔주면 GameObject가 아닌 몬스터 컴포넌트가 들어감
> ```C#
> [SerializeField]
> Monster enemy;
> ```  
> **그럼 몬스터 오브젝트를 넣어줬을 때 몬스터 오브젝트가 아닌 몬스터 오브젝트의 몬스터 컴포넌트가 들어가게 된다**  
> **게임 오브젝트에 추가된 몬스터 스크립트가 아닌 그냥 몬스터 스크립트를 넣으면 추가되지 않음(객체만 들어갈 수 있음)**  
> **따라서 다음과 같이 몬스터 오브젝트의 값 변경이 가능하게 됨**  
> ```C#
> void Start()
> {
>      enemy.hp -= damage;
> }
> ```  
> **실행하면 플레이어 데미지 만큼 몬스터의 hp가 깎인 것을 툴에서 확인할 수 있음**

<br>

#### 클래스 변수들은 참조값 기반이라 원본을 건드릴 수 있음
#### 구조체는 그냥 복사


#### enemy에 아무런 스크립트도 넣지 않고 실행하면 `NullReferenceException` 에러
* 이렇게 하면 예방 가능
```C#
void Start()
{
   if (enemy !=null)
      enemy.hp -= damage;
}
```
