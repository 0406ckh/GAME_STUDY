# 애니메이터
애니메이션은 여러개가 될 수도 있기 때문에 그것을 컨트롤 해주어야 함  

<br>

### 컨트롤러
이전에 애니메이션을 만들었을 때 만들어진 파일 2개 중 세모파일이 아닌 다른 파일이 컨트롤러  
컨트롤러를 클릭해서 들어가면 흐름도가 보임  
`Entry`는 시작할 떄 어떤 애니메이션을 적용할 지 결정함  

<br> 

필요한 애니메이션들을 이전처럼 파일 밑어 넣어줌  
만들어진 오브젝트들과 컨트롤러들은 사용할 것 하나만 남기고 삭제  
세모 파일들은 전부 컨트롤러 화면에 드래그 해서 넣어줌  

<br>

애니메이션을 우클릭 후 `Set as Layer Default State`를 선택해주면 선택한 애니메이션이 기본상태로 적용돼 시작하면 선택한 애니메이션이 나옴
