# 이동

### 플레이어 이동 간단하게
```C#
// Player.cs
void Update()
{
    if (Input.GetKey(KeyCode.W))
    {
        // transform으로 좌표를 조정하니 transform 컴포넌트에서 position을 가져옴
        // transform.position.y += 1; 는 안됨
        transform.position += new Vector3(0, 1, 0);
    }
    if (Input.GetKey(KeyCode.A))
    {
        transform.position += new Vector3(-1, 0, 0);
    }
    if (Input.GetKey(KeyCode.S))
    {
        transform.position += new Vector3(0, -1, 0);
    }
    if (Input.GetKey(KeyCode.D))
    {
        transform.position += new Vector3(1, 0, 0);
    }
}
```
**위같이 하면 플레이어가 엄청 빠르게 움직임**  
**update 함수가 매 프레임마다 한번씩 호출되는 반복적인 함수라서 누르고 있을 동안에 계속 적용이 되기 때문에 1이 반복적으로 엄청나게 추가되기 때문**  

<br>

### 속도에 맞춰서 플레이어 이동하기
```C#
// Player.cs
public class Player : MonoBehaviour
{
    public float speed = 5.0f;

    // Update is called once per frame
    void Update()
    {
        // 이동 거리 = 속도 * 시간
        // 한 프레임 동안 이동해야하는 거리를 구해야 함
        // 한 프레임의 시간에 속도를 곱하면 한 프레임동안 이동하는 거리가 구해짐
        // Time.deltaTime = 이전 프레임에서 현재 프레임까지 경과된 시간
        float moveDistance = speed * Time.deltaTime;
        
        if (Input.GetKey(KeyCode.W))
        {
            // transform으로 좌표를 조정하니 transform 컴포넌트에서 position을 가져옴
            transform.position += new Vector3(0, moveDistance, 0);
        }
        if (Input.GetKey(KeyCode.A))
        {
            transform.position += new Vector3(-moveDistance, 0, 0);
        }
        if (Input.GetKey(KeyCode.S))
        {
            transform.position += new Vector3(0, -moveDistance, 0);
        }
        if (Input.GetKey(KeyCode.D))
        {
            transform.position += new Vector3(moveDistance, 0, 0);
        }
    }
}
```
**하지만 위같은 코드에선 wd 같이 대각선으로 움직일 때 w 방향으로도 속도만큼 움직이고 d 방향으로도 속도만큼 움직이기 때문에 원래 속도보다 더 빠르게 움직이게 됨**  

<br>

### 대각선으로도 속도에 맞춰 움직이기
```C#
// Player.cs
public class Player : MonoBehaviour
{
    public float speed = 5.0f;

    // Update is called once per frame
    void Update()
    {
        // 이동 거리 = 속도 * 시간
        // 한 프레임 동안 이동해야하는 거리를 구해야 함
        // 한 프레임의 시간에 속도를 곱하면 한 프레임동안 이동하는 거리가 구해짐
        // Time.deltaTime = 이전 프레임에서 현재 프레임까지 경과된 시간
        float moveDistance = speed * Time.deltaTime;

        // 움직일 방향을 설정해줘야 함
        // Vector3.zero는 new Vector3(0, 0, 0)을 의미함
        Vector3 moveDirection = Vector3.zero;

        if (Input.GetKey(KeyCode.W))
        {
            // 이동하고 싶은 방향을 적용해줌
            // Vector3.up은 new Vector3(0, 1, 0)을 의미함
            moveDirection += Vector3.up;
        }
        if (Input.GetKey(KeyCode.A))
        {
            // Vector3.left는 new Vector3(-1, 0, 0)을 의미함
            moveDirection += Vector3.left;
        }
        if (Input.GetKey(KeyCode.S))
        {
            // Vector3.down은 new Vector3(0, -1, 0)을 의미함
            moveDirection += Vector3.down;
        }
        if (Input.GetKey(KeyCode.D))
        {
            // Vector3.right은 new Vector3(1, 0, 0)을 의미함
            moveDirection += Vector3.right;
        }

        // 방향은 위에서 정해주었고 이제 그 방향으로 거리만큼 이동시켜 줘야함
        // moveDirction는 아직 정규화 되지 않음
        // normalized로 정규화 시켜서 방향을 가리키는 단위벡터로 변환시켜줘야 함
        transform.position += moveDirection.normalized * moveDistance;
    }
}
```
