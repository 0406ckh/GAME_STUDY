# 플레이어 코드로 만들어보기

### 게임 오브젝트 만드는 방법
> **1번째: 2D Object -> Sprites -> Circle**  
> **2번째: Ctrl +Shift + N(게임 오브젝트 생성) -> Player로 이름 변경 -> Component에 Sprite Renderer 추가 -> Player 스크립트 만들고 Component에 추가**  
> **위를 코드로 만들어야 함**  

<br>

## 코드로 플레이어 만들기
### 1. 코드에 new Gameobject() 추가**  
> ```C#
> //Player.cs
> using UnityEngine;
> 
> public class MainScript : MonoBehaviour
> {
>     void Start()
>     {
>         GameObject go = new GameObject();
>     }
> 
> }
> ```
> **`GameObject go = new GameObject();` : 새로운 게임 오브젝트 동적으로 생성**  
> **실행하면 아래와 같이 Scene에 New Game Object 추가됨**
> ![Image](https://github.com/user-attachments/assets/8569bf32-267f-46d1-8f9b-e8baad92e6cf)  
> **Start안에 코드가 들어가있지만 Start가 끝난다고 오브젝트가 사라지진 않음. 게임 실행이 끝나면 사라짐**  

<br>

### 2. 게임 오브젝트 이름 수정
> ```C#
> //Player.cs
> void Start()
> {
>     GameObject go = new GameObject();
>     go.name = "Player";
> }
> ```
> **오브젝트 이름이 Player로 만들어짐**  

<br>

### 3. Component 추가하기
> ```C#
> //Player.cs
> void Start()
> {
>     GameObject go = new GameObject();
>     go.name = "Player";
> 
>     //1번
>     go.AddComponent<SpriteRenderer>();
>     SpriteRenderer sr = go.GetComponent<SpriteRenderer>();
> 
>     //2번
>     SpriteRenderer sr = go.AddComponent<SpriteRenderer>();
> }
> ```
> **`go.AddComponent<SpriteRenderer>();` : 컴포넌트 추가. <>안에 클래스 입력하면 입력한 클래스의 컴포넌트가 추가됨**  
> **`go.GetComponent<SpriteRenderer>();` : 이미 있는 게임 컴포넌트를 갖고 옴**  
> **`go.AddComponent<SpriteRenderer>();`는 SpriteRenderer 타입으로 리턴하기 때문에 1번처럼 2단계가 아닌 2번처럼 한번에 할 수 있음**  

<br>

### 4. Sprite와 Color 추가(툴에서 드래그 하는 방식 그대로 사용. 추후 코드로 변경하는 방법 나옴)
> ```C#
> //Player.cs
> public class MainScript : MonoBehaviour
> {
>     public Sprite sprite; 		  // sprite 받기
>     void Start()
>     {
>         GameObject go = new GameObject();
>         go.name = "Player";
> 
>         SpriteRenderer sr = go.AddComponent<SpriteRenderer>();
>         //SpriteRenderer sr = go.GetComponent<SpriteRenderer>();
> 
>         sr.sprite = sprite;    	 // 받은 sprite를 sprite renderer에다 연결
>         sr.color = Color.green; 	 // 색상 지정
>     }
> }
> ```
> **실행해도 툴에선 Sprite가 None이라 안보이니까 Circle 오브젝트에서 복사해서 Sprite에 Circle 붙여넣어줘야 보임**  

<br>

### 5. Player 컴포넌트 추가
> ```C#
> //Player.cs
> void Start()
> {
>     GameObject go = new GameObject();
>     go.name = "Player";
> 
>     SpriteRenderer sr = go.AddComponent<SpriteRenderer>();
> 
>     sr.sprite = sprite;
>     sr.color = Color.green;
> 
>     Player player = go.AddComponent<Player>();
> }
> ```

<br>

### `CreatePlayer()` 함수 만들어서 실행하기
> ```C#
> //Player.cs
> using UnityEngine;
> 
> public class MainScript : MonoBehaviour
> {
>     public Sprite sprite;
>     void Start()
>     {
>         CreatePlayer();
>     }
> 
>     void CreatePlayer()
>     {
>         GameObject go = new GameObject();
>         go.name = "Player";
> 
>         SpriteRenderer sr = go.AddComponent<SpriteRenderer>();
> 
>         sr.sprite = sprite;
>         sr.color = Color.green;
> 
>         Player player = go.AddComponent<Player>();
>     }
> }
> ```
