# 피킹
화면에 표시된 오브젝트를 선택하는 기술

### 화면 좌표 찍어보기
```C#
// MainScript.cs
public class MainScript : MonoBehaviour
{
    void Update()
    {
        if(Input.GetMouseButtonDown(0))
        {
            Debug.Log(Input.mousePosition);
        }
    }
}
```
마우스로 찍어보면 게임 내의 좌표가 아닌 스크린의 좌표를 표시해줌  
이 좌표를 게임 내 좌표로 치환하는 것이 목표  

<br>

유니티 상에서 보이는 오브젝트들은 2D로 보이지만 사실은 3D로 돼있음  
메인 카메라 오브젝트에 `Projection`의 `Orthographic`은 객체를 원근감 없이 2D로 보여주기 때문에 z좌표가 멀리 있어도 크기는 동일하게 보임  
`Scene`에서 3D로 전환하면 확인 가능  
따라서 우리가 보는 2D 좌표를 3D 좌표로 변환해야 함  

<br>

### 스크린 좌표를 게임 좌표로 변환해서 로그 띄우기
```C#
// MainScript.cs
public class MainScript : MonoBehaviour
{
    void Update()
    {
        if (Input.GetMouseButtonDown(0))
        {
            // 스크린 좌표를 게임 월드 좌표로 변환시켜서 벡터로 가져옴
            Vector3 worldPos = Camera.main.ScreenToWorldPoint(Input.mousePosition);

            // 가상의 레이저를 쏘아 제일 먼저 맞는 물체의 위치를 가져옴(레이캐스팅)
            // worldPos는 시작 위치, Vector2.zero는 방향
            // Vecter2.zero는 z축으로 쏘겠다는 의미. 왼쪽으로 쏘고 싶으면 left, 오른쪽은 right해주면 됨
            RaycastHit2D hit = Physics2D.Raycast(worldPos, Vector2.zero);

            // 게임 개발 화면상에서 레이저를 시각적으로 보여주게 하는 함수
            // worldPos는 시작 위치, Vector3.forward은 방향, Color.red는 색, 3은 보여주는 시간(초)
            // 3차원 좌표이기 때문에 Vector3 사용하여 forward로 방향 정해줌
            // 100을 곱해주는 이유는 표시되는 선의 길이까지 정해주는 것
            Debug.DrawRay(worldPos, Vector3.forward * 100, Color.red, 3);

            // 레이저가 맞으면 맞은 오브젝트의 이름을 가져옴
            if (hit.collider != null)
            {
                Debug.Log(hit.collider.name);
            }
        }
    }
}
```
