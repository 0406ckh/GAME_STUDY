# 스프라이트 애니메이션
그림 한장 한장을 빠르게 보여주는 방식  
애니메이션이 이쁘게 나오고 한계가 없는 대신 노가다가 심함  

<br>

일반 오브젝트를 만들고 `Sprite Renderer`의 컴포넌트에 넣고 싶은 이미지를 넣으면 오브젝트에 이미지가 적용된 것을 확인할 수 있음  
애니메이션으로 움직임을 적용하고 싶으면 이미지를 순서대로 넣어주어야 함  
`이미지1`, `이미지2`, `이미지3` ... 이런 식으로 넣을 때 이미지 사이의 간격을 신경 써야함  
따라서 이미지를 합쳐서 하나의 애니메이션으로 구성시켜 관리하는 것이 효율적임  

<br>

### 애니메이션 만들기
`Resources` 밑의 이미지들 중 합쳐서 애니메이션으로 만들고 싶은 이미지들을 선택한 후 `Hierachy`로 드래그  
`Create New Animation`으로 파일 저장을 할 수 있는데 `Resources` 산하에 새 폴더를 만들어서 저장  

<br>

`Hierachy`에 방금 만든 이미지 명으로 오브젝트가 생성된 것을 확인할 수 있음  
기본적으로 `Spirte Renderer`와 `Animator` 컴포넌트가 한번에 만들어진 것을 확인할 수 있음  

<br>

폴더 안에 이미지 이름으로 된 파일 하나와 세모가 붙어있는 파일 하나가 만들어져있음  
**세모 모양으로 돼있는 것이 사용할 애니메이션 파일**  

<br>

### Animation
세모 파일을 더블클릭 하면 `Animation`이라는 창이 나옴  
만들어진 오브젝트를 클릭하고 플레이 버튼을 누르면 애니메이션이 실행되는 것을 확인할 수 있음  

<br>

타임라인을 조정하여 이미지 사이의 간격 조정 가능  
Sprite 하나를 드래그해서 추가해주는 것도 가능함  
스프라이트 변경 말고 다른 행동도 취하고 싶으면 `Add Property`로 추가 가능  
추가한 Property는 `Remove Property`로 삭제 가능  

<br>

### Spine 애니메이션
3d 게임을 만드는 것 처럼 부위별로 캐릭터를 만들어 뼈대를 심어 움직이는 방식  
작업 속도가 더 빠르지만 스프라이트 애니메이션 보다 조금 더 어색함  

스파인 애니메이션은 유니티에서 기본적으로 지원하는 기능이 아니라 추가적인 설정이 필요하지만 애니메이션 작업 코드 같은 큰 틀은 비슷함
